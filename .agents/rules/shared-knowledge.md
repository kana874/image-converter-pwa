# Antigravity 2 shared knowledge rule

作業開始時に `.ai/INDEX.md` を全文読み、そこから現行仕様、状態、既知事項へ移動してください。

- Antigravity 2の出所識別子は `ai:antigravity-2` です。
- 製品機能は `README.md` と実装を正本として扱います。
- 変更は作業ブランチとDraft Pull Requestで提案します。
- このPublicリポジトリへprivate情報、資格情報、個人情報、ローカルパスを保存しません。
- `main` への直接更新、Pull Requestの承認・マージ、削除、履歴書き換えは禁止します。
